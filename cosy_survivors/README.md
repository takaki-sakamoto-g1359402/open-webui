# Cosy Survivors

## セットアップ
1. [Godot 4.3](https://godotengine.org/) をインストール。
2. このフォルダをエディタで開くとすぐに実行できます。

## エクスポート
- Android (ARMv8)
- Windows / macOS

## 調整
`res://data/*.json` を編集して武器・敵・ウェーブを調整できます。

## モバイル最適化
- 60FPS 目標。プールでオブジェクトを再利用。
- 描画バッチを減らすためプレースホルダーの色形のみ使用。
