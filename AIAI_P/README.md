# Artificial Innovator AI Plus

This directory contains a minimal prototype that plans innovation roadmaps between organizations.

## Usage

### CLI
```bash
python aiai_p.py ask.txt [--feedback success|fail] [--viz]
```

### Streamlit Dashboard
```bash
streamlit run app.py
```

### Scheduler
```bash
python scheduler.py
```

All outputs are stored in the current working directory. Roadmaps are logged in `history.db`.
