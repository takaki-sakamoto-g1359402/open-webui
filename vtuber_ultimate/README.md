# vtuber_ultimate

A lightweight framework for building autonomous VTuber agents.

## Setup

```bash
pip install -r requirements.txt
```

## Usage

```bash
python vtuber_ultimate/run.py --persona "StellarReaper" --lang ja,en --demo
```

The `--demo` flag generates dummy datasets under `vtuber_ultimate/data/`.
Fill out `config.yaml` with your API keys for production use.
